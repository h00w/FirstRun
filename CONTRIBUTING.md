# Contributing

1. Select a bounded task from the [roadmap](docs/ROADMAP.md).
2. Create a branch and explain the problem and expected behavior in the PR.
3. Run the verification commands in the [README](README.md).
4. Merge only after the required checks pass.

Keep credentials, personal data and generated build artifacts out of commits.
Choose the runtime, dependency policy and license when the project scope is agreed.
